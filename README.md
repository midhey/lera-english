# Английский с Лерой

Одностраничный сайт и мини-админка, в которой Лера сама меняет тексты, цены, отзывы, вопросы и фото.
Без зависимостей: Node и Caddy.

## Как устроено

- `content.default.json` — исходные тексты, с них начинается контент при первом запуске.
- `src/render.js` — шаблон страницы и страницы 404. Всё, что приходит из админки, экранируется (`src/html.js`).
- `src/schema.js` — какие поля есть в админке и как они проверяются перед публикацией.
- `src/server.js` — сервис админки. При публикации пересобирает `public/index.html`.
- `src/auth.js`, `src/set-password.js` — вход в админку.
- `admin/` — страницы админки и входа.
- `public/` — то, что отдаёт Caddy: `assets/` из репозитория, собранные `index.html`, `404.html`, `robots.txt`, `sitemap.xml` и `uploads/` с фото из админки.
- `data/` — опубликованный контент, история версий (последние 100) и хэш пароля. В git не хранится.

Сайт — обычная статика: если сервис админки упадёт, сайт продолжит открываться.
Блоки «Цены», «Отзывы» и «Вопросы» с пустым списком на сайте не показываются вместе с пунктом меню.

## Локально

```bash
npm run dev
```

Сайт — http://127.0.0.1:8765/, админка — http://127.0.0.1:8765/admin/ (локально без пароля). Нужен Node 14.17+.

## Вход в админку

- Страница входа — `/admin/login`, только пароль. Вход запоминается на устройстве на 30 дней, есть кнопка «Выйти».
- На сервере хранится только scrypt-хэш пароля (`data/auth.json`), в переменных окружения пароля нет.
- После 10 неверных паролей вход с этого адреса блокируется на 15 минут.
- Сменить пароль (заодно выкинет все устройства):
  ```bash
  sudo -u lera node /srv/lera/src/set-password.js
  ```

## Сервер: первый раз

1. Поставить Node 20+ и Caddy.
2. Выложить код — создаст пользователя `lera`, `/srv/lera`, сервис `lera-admin` и спросит пароль админки:
   ```bash
   DEPLOY_HOST=root@сервер sh deploy/deploy.sh
   ```
3. Взять блок из `deploy/Caddyfile.example` в Caddyfile и сделать `sudo systemctl reload caddy`.
4. Проверить вход с телефона Леры: открыть https://lera.midhey.ru/admin/ из Telegram.
5. Добавить сайт в Яндекс.Вебмастер и Google Search Console (проще всего подтвердить через DNS-запись) и отправить `https://lera.midhey.ru/sitemap.xml`.

При переезде на свой домен — поменять домен в Caddyfile и `SITE_URL` в `/etc/lera-admin.env`, затем `sudo systemctl restart lera-admin`.

## Обновление

```bash
DEPLOY_HOST=root@сервер sh deploy/deploy.sh
```

Скрипт копирует код и перезапускает сервис, при старте страница пересобирается.
Контент и фото на сервере не трогаются — их меняет только админка.

Если добавляешь поле: опиши его в `src/schema.js`, выведи в `src/render.js` и задай значение в `content.default.json` —
у уже сохранённого контента новое поле получит это значение.

## Бэкап

```bash
DEPLOY_HOST=root@сервер sh deploy/backup.sh
```

Забирает контент, историю версий и фото из админки в `backups/<дата>/` (хэш пароля не копирует).

## Если что-то сломалось

- Откатить контент — «История публикаций» в админке.
- Логи сервиса — `journalctl -u lera-admin -n 50`.
